# Certificate images

Empty by design. No certificate scans are published yet.

Before any certificate image or PDF is committed here it must be checked, and redacted where needed, for:

- National identity number (CNIC) and passport number
- Service number, employee number or any institutional identifier
- Date of birth, where not required
- Home address and telephone number
- Signature
- QR codes or verification identifiers that expose private information
- Any military unit, base, location or role detail

The original unredacted document stays outside this repository. Only a redacted copy is committed, and the original is never overwritten.
