## Overview

Internal tools built inside Google Workspace for businesses that already live there: scripted spreadsheets, programmatically generated forms, mailbox architecture, Drive structure, and the Workspace troubleshooting nobody else wants to take on.

## Problem

Small businesses accumulate Workspace sprawl. Files land at the root because that is where the upload dialog opens. Two people invent two folder schemes. A spreadsheet grows a script someone wrote once and nobody understands. A mailbox reaches the point where finding anything takes longer than doing the work.

None of this is glamorous and all of it costs real hours every week.

## My role

Sole delivery on each engagement — scoping, building, testing and handover.

## Work performed

- Repaired and extended existing Apps Script where the original author was long gone
- Generated a 617-question form programmatically rather than by hand
- Built scripted spreadsheet tools that a non-technical team operates without help
- Restructured overloaded business mailboxes with labels, filters and rules
- Designed Drive folder architectures with naming conventions a team can follow
- Diagnosed Workspace faults that had been worked around rather than fixed

## Tools

Google Apps Script · Sheets · Gmail · Drive · Forms · Docs · Calendar · Contacts · time-driven triggers

## Solution

Readable, documented scripts rather than clever ones. A structure the client's own staff can extend. A written handover so the system survives after the engagement ends.
